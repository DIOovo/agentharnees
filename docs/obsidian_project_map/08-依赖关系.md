## 启动依赖

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

由于数据库 URL 是相对路径，建议从项目根目录启动。Python 最低版本未明确声明；源码使用 `str | None`、`dict[str, ...]` 和 `removeprefix`，至少需要 Python 3.9，联合类型语法实际要求 Python 3.10+。
